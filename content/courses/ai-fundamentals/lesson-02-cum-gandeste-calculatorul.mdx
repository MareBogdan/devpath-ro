## Cum "gândește" un calculator

În Lecția 1 ai văzut că AI-ul descoperă pattern-uri din date. Dar acum apare întrebarea logică:

**Cum procesează de fapt un calculator o imagine, un text sau un sunet?**

Răspunsul este surprinzător de simplu: **totul sunt numere**.

---

### Totul este număr

Un calculator nu știe ce e o pisică, o față, sau un cântec. Știe doar să lucreze cu numere. Orice altceva — imagini, text, audio — se traduce în numere înainte de a fi procesat.

**O imagine = o matrice de numere**

```python
# O imagine de 4x4 pixeli în grayscale (0 = negru, 255 = alb)
imagine = [
    [255, 200, 150, 100],  # primul rând de pixeli
    [180, 210,  90,  60],  # al doilea rând
    [120, 170, 230, 200],  # al treilea rând
    [ 80, 100, 140, 190]   # al patrulea rând
]

# O imagine reală de 1920x1080 pixeli are ~2 milioane de numere
# Pentru color (RGB): înmulțești cu 3 canale → ~6 milioane de numere
```

**Text = numere (tokenuri)**

```python
# Calculatorul nu vede litere — vede indecși din vocabular
text = "Salut, lume!"

# Tokenizare simplificată:
vocabular = {"Salut": 1547, ",": 11, " ": 220, "lume": 8923, "!": 0}
tokenuri  = [1547, 11, 220, 8923, 0]

# ChatGPT operează cu ~50.000 de tokenuri în vocabularul său
# Fiecare token e, în medie, ~4 caractere
```

**Audio = valori de undă**

```python
import numpy as np

# Un fișier audio de 1 secundă la 44.100 Hz = 44.100 numere
sunet = np.array([0.0, 0.12, 0.34, 0.45, 0.23, -0.12, -0.34, ...])

# Whisper (AI de transcriere de la OpenAI) procesează exact aceste valori
# și le transformă înapoi în text
```

---

### De ce contează asta pentru AI?

Acum că totul e număr, **AI-ul poate face matematică pe el**. Și matematica poate găsi pattern-uri.

Gândește-te la asta:
- 10.000 imagini cu pisici → 10.000 de matrici de numere
- AI-ul caută ce **combinații de numere** apar constant la pisici
- Dacă zona din colțul stâng sus are valori mari (blană deschisă) și există valori specifice pentru urechi... → probabil pisică

Nu e magic. E căutare de pattern-uri în spații de numere cu milioane de dimensiuni.

### Programare clasică vs Machine Learning

Aceasta este cea mai importantă distincție din AI:

**Programare clasică: Date + Reguli → Rezultat**

```python
# Tu scrii regulile manual:
def clasifica_email(email):
    cuvinte_spam = ["loterie", "câștigat", "click aici", "urgent"]
    for cuvant in cuvinte_spam:
        if cuvant in email.lower():
            return "SPAM"
    return "INBOX"

# Problema: spammerii adaptează instant mesajele pentru a evita regulile
# "Ai c4știgat! Clic4 aic1!" → trece de filtru
```

**Machine Learning: Date + Rezultate dorite → Reguli (descoperite automat)**

```python
from sklearn.naive_bayes import MultinomialNB

# Tu dai exemple, modelul descoperă regulile:
model = MultinomialNB()
model.fit(

# Acum modelul știe să filtreze, inclusiv variante noi de spam pe care
```

### Cum "învață" un model — intuiția

Imaginează-ți că vrei să înveți un prieten să ghicească vârsta cuiva dintr-o poză.

1. Îi arăți 1.000 de poze și îi spui vârsta reală a fiecărei persoane
2. El face predicții → le compari cu vârsta reală → calculezi eroarea
3. Îi spui cât de greșit a fost ("ai zis 25, realitatea e 45 — eroare mare!")
4. El ajustează modul în care "privește" poza
5. Repeți de mii de ori, cu mii de poze

**Exact asta face un model de Machine Learning:**

```python
# Pseudocod pentru training (antrenare):
for epoca in range(1000):
    predictii = model.predict(date_antrenare)
    eroare = calculeaza_eroarea(predictii, varste_reale)

    # "Backpropagation" — ajustează parametrii pentru a reduce eroarea
    model.ajusteaza_parametrii(eroare)

    if epoca % 100 == 0:
        print(f"Epoca {epoca}: eroare = {eroare:.4f}")

# Epoch   0: eroare = 0.8341  ← modelul habar nu are
# Epoch 100: eroare = 0.4217
# Epoch 500: eroare = 0.1083
# Epoch 999: eroare = 0.0342  ← modelul a "învățat"!
```

Mii de parametri interni (numere) se ajustează iterativ pentru a face predicții din ce în ce mai bune. Asta e tot "learning"-ul din Machine Learning.

### Unde excelează AI vs unde eșuează

**AI excelează la:**
- Procesarea a milioane de exemple fără oboseală
- Găsirea de pattern-uri subtile în volume masive de date
- Consistență — face același lucru la fel de bine a 1.000.000-a oară

**AI eșuează la:**
- Raționament abstract general ("dacă A atunci B, dacă B atunci C...")
- Înțelegerea contextului nuanțat și a ironiei
- Generalizare la situații complet noi, nevăzute în antrenare
- Certitudine — orice predicție e probabilistică, nu "știe" cu siguranță

> **Key insight:** AI-ul e un instrument extraordinar de puternic, cu limitări clare. Înțelegând ambele aspecte, îl vei folosi mult mai eficient.

### Recapitulare

✅ **Totul sunt numere** — imagini, text, audio se convertesc la matrici de numere
✅ **Programare clasică** = Tu dai regulile → Calculatorul aplică

✅ **Training** = reducerea erorii prin ajustarea iterativă a milioane de parametri
✅ AI excelează la **pattern-uri în volume mari**, nu la raționament abstract
