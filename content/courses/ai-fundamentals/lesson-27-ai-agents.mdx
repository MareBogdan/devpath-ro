## AI Agents — ce sunt, cum funcționează, exemple reale

Un chatbot răspunde la întrebări. Un **agent AI** ia acțiuni autonome pentru a îndeplini obiective complexe. Diferența e enormă.

---

### Ce e un Agent AI

**Definiție:** Un agent AI este un sistem care percepe mediul, ia decizii și execută acțiuni în mod iterativ pentru a atinge un obiectiv, fără supraveghere umană la fiecare pas.

```
CHATBOT:   User → LLM → Răspuns text
AGENT AI:  User → LLM → Decizie → Unealtă → Observație → LLM → Decizie → ... → Rezultat
```

Componentele unui agent:
1. **LLM (Creierul)** — planifică, decide, raționează
2. **Tools/Unelte** — ce poate face agentul (search, code execution, DB, API)
3. **Memory/Memorie** — contextul curent + istoricul
4. **Planning** — descompune task-uri complexe în pași
5. **Observation** — feedback-ul de la unelte, folosit la pasul următor

---

### Pattern-ul ReAct — Reason + Act

Cel mai folosit pattern pentru agenți:

```python
import json
from openai import OpenAI

client = OpenAI()

# Definim uneltele agentului
tools = [
    {
        "type": "function",
        "function": {
            "name": "search_web",
            "description": "Caută informații pe internet",
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {"type": "string", "description": "Termenul de căutat"}
                },
                "required": ["query"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "run_python",
            "description": "Execută cod Python și returnează output-ul",
            "parameters": {
                "type": "object",
                "properties": {
                    "code": {"type": "string", "description": "Codul Python de executat"}
                },
                "required": ["code"]
            }
        }
    }
]

# Implementarea uneltelor
def execute_tool(name: str, args: dict) -> str:
    if name == "search_web":
        # În producție: integrare cu Serper, Tavily, SerpAPI, etc.
        return f"Rezultate căutare '{args['query']}': [rezultate de la search API]"
    elif name == "run_python":
        try:
            import io, contextlib
            output = io.StringIO()
            with contextlib.redirect_stdout(output):
                exec(args["code"])  # ATENȚIE: sandbox în producție!
            return output.getvalue() or "Cod executat (fără output)"
        except Exception as e:
            return f"Eroare: {str(e)}"
    return f"Unealtă necunoscută: {name}"

# Agent loop principal
def run_agent(task: str, max_steps: int = 10) -> str:
    """Agent simplu cu loop ReAct. Continuă până modelul dă răspuns final."""
    messages = [
        {
            "role": "system",
            "content": """Ești un agent AI care rezolvă task-uri pas cu pas.
Folosește uneltele disponibile când ai nevoie de informații externe sau calcule.
Când ai toate informațiile, dă răspunsul final fără a mai apela unelte."""
        },
        {"role": "user", "content": task}
    ]

    for step in range(max_steps):
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=messages,
            tools=tools,
            tool_choice="auto"
        )

        msg = response.choices[0].message

        if msg.tool_calls:
            messages.append(msg)

            for tool_call in msg.tool_calls:
                func_name = tool_call.function.name
                func_args = json.loads(tool_call.function.arguments)
                result = execute_tool(func_name, func_args)

                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": result
                })
        else:
            return msg.content  # Răspuns final

    return "Max pași atinși fără răspuns final"

# Exemplu:
# answer = run_agent("Calculează câte secunde sunt într-un an și afișează rezultatul formatat")
```

### Tipuri de memorie pentru agenți

```python
# 1. MEMORIE ÎN CONTEXT (Working Memory)
# → Conversația curentă (messages list)
# → Se pierde la sfârșitul sesiunii
# → Limitată de context window (128k tokeni la GPT-4)
working_memory = []  # Lista de mesaje

# 2. MEMORIE EXTERNĂ SEMANTICĂ (Long-term Memory)
# → Stocată în vector DB (Supabase pgvector, Pinecone)
# → Persistă între sesiuni
# → Retrieval prin similarity search
# → Exemplu: "Utilizatorul preferă răspunsuri scurte, limbaj tehnic"
semantic_memory_db = None  # Vector DB connection

# 3. MEMORIE PROCEDURALĂ
# → Cum să execute task-uri
# → Encoded în system prompt sau fine-tuning
# → Ex: "Mereu verifică soluția înainte de a o returna"
procedural_memory = """
REGULI DE LUCRU:
- Verifică întotdeauna codul înainte de a-l returna
- Citează sursele pentru afirmații factuale
- Dacă un pas eșuează, încearcă o altă abordare
"""

# 4. CACHE SEMANTIC (Episodic Memory)
# → Perechi (query, răspuns) pentru întrebări frecvente
# → Evită apeluri API repetate pentru aceleași întrebări
response_cache = {}

def smart_agent_response(query: str) -> str:
    # Verifică cache-ul mai întâi
    if query in response_cache:
        return response_cache[query]

    # Retrievi memorie relevantă
    # relevant_memories = semantic_memory_db.search(query, top_k=3)

    # Rulează agentul cu context din memorie
    answer = run_agent(query)

    # Stochează în cache și în memorie pe termen lung
    response_cache[query] = answer
    # semantic_memory_db.store(query, answer)

    return answer
```

### Autonomie vs Control — trade-off-ul fundamental

```python
# NIVELURI DE AUTONOMIE:

autonomy_levels = {
    "manual": "Omul face tot, AI-ul doar sugerează",
    "copilot": "AI propune, omul aprobă fiecare acțiune",
    "supervised": "AI execută acțiuni low-risk automat, cere aprobare pentru high-risk",
    "semi_autonomous": "AI execută automat, omul poate interveni",
    "fully_autonomous": "AI execută complet autonom (risc ridicat!)",
}

# Best practice: Human-in-the-Loop pentru acțiuni ireversibile
def safe_action(action: str, risk: str, args: dict) -> str:
    """
    risk: "low" (auto), "medium" (loghează), "high" (cere aprobare)
    """
    if risk == "high":
        print(f"⚠️ Acțiune ireversibilă: {action}({args})")
        if input("Aprobi? (y/n): ").lower() != "y":
            return "Acțiune respinsă"

    return execute_tool(action, args)

# Acțiuni care MEREU necesită aprobare:
high_risk_actions = [
    "delete_file", "send_email", "post_to_social_media",
    "make_payment", "modify_database", "deploy_to_production"
]
```

### Recapitulare

✅ **Agent AI = LLM + Tools + Memory + Planning** — nu doar chatbot
✅ **ReAct pattern:** Reason → Act → Observe → Repeat until done
✅ **Tipuri de memorie:** în context (temporară), externă (persistentă), procedurală
✅ **Multi-agent:** orchestrator coordonează agenți specializați pentru task-uri complexe
✅ **Autonomie vs Control:** human-in-the-loop obligatoriu pentru acțiuni ireversibile
