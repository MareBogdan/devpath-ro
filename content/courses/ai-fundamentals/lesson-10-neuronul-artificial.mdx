## Cum funcționează un neuron artificial

Bun venit în **Modulul 3 — Rețele Neuronale și Deep Learning**!

Dacă Modulul 2 a explicat cum "învață" un sistem, Modulul 3 intră în interiorul celui mai puternic tip de model din AI modern: **rețeaua neuronală**.

Totul începe cu o singură piesă: **neuronul artificial**.

---

### Neuronul biologic — inspirația

Creierul uman conține aproximativ **86 de miliarde de neuroni**. Fiecare neuron este o celulă care:
1. Primește semnale electrice de la alți neuroni (prin dendrite)
2. Le adună și procesează
3. Dacă suma depășește un prag, "se activează" și transmite un semnal mai departe (prin axon)

```
Dendrite → [Corp celular: sumează semnalele] → Axon → următorul neuron
              ↑ Dacă suma > prag → se activează
```

Rețelele neuronale artificiale sunt o **abstracție matematică** a acestui mecanism. Nu simulează biologia în detaliu — pur și simplu se inspiră din principiu.

---

### Neuronul artificial (Perceptronul)

Un neuron artificial, numit și **perceptron**, face exact trei lucruri:

**1. Primește input-uri cu ponderi (weights)**
**2. Le sumează ponderat**
**3. Aplică o funcție de activare**

```
x₁ ──w₁──┐
x₂ ──w₂──┤→ Σ(xᵢ × wᵢ) + bias → Funcție activare → Output
x₃ ──w₃──┘
```

**Exemplu concret — evaluarea unui email ca spam:**

```python
import numpy as np

# Caracteristici (features) ale unui email:
x = np.array([
    1,    # conține cuvântul "gratuit"
    0,    # nu conține "câștigați"
    1,    # are mai mult de 5 link-uri
    0.8,  # scorul de urgență (0-1)
])

# Ponderile (weights) — cât de important e fiecare feature:
w = np.array([0.7, 0.9, 0.5, 0.6])

# Bias — un offset care ajustează sensibilitatea
bias = -0.5

# Suma ponderată:
z = np.dot(x, w) + bias
# z = (1×0.7) + (0×0.9) + (1×0.5) + (0.8×0.6) + (-0.5)
# z = 0.7 + 0 + 0.5 + 0.48 - 0.5 = 1.18

print(f"Suma ponderată (z): {z}")  # 1.18
```

---

### Funcțiile de activare — "Pragul" neuronului

Suma ponderată brută `z` poate fi orice număr real. Funcția de activare îl **transformă** într-un output util.

**Sigmoid — între 0 și 1 (probabilitate)**
```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

output = sigmoid(1.18)
print(f"Probabilitate spam: {output:.2%}")  # 76.48%
```

**ReLU — Rectified Linear Unit (cel mai popular azi)**
```python
def relu(z):
    return max(0, z)

# ReLU(1.18) = 1.18
# ReLU(-0.5) = 0   ← neuronul "tace" dacă suma e negativă
```

**Tanh — între -1 și 1**
```python
def tanh(z):
    return np.tanh(z)

# Simetric față de 0, util pentru date normalizate
```

**De ce avem nevoie de funcții de activare?**

Fără funcție de activare, oricât de multe straturi ar fi, rețeaua neuronală rămâne o simplă **regresie liniară**. Funcțiile de activare introduc **non-linearitate** — capacitatea de a modela pattern-uri complexe, curbe, decizii nelineare.

---

### Ponderile (Weights) — Inima neuronului

Ponderile `w` sunt **ceea ce modelul învață în timpul antrenării**.

La inițializare, ponderile sunt aleatorii:
```python
w = np.random.randn(4) * 0.01
# [0.0032, -0.0071, 0.0019, -0.0054]  ← complet aleatoriu, inutil
```

Prin gradient descent (Lecția 7), ponderile se ajustează treptat:
```
Epoca 1:   w = [0.0032, -0.0071, ...]  → Loss = 2.34
Epoca 100: w = [0.312,   0.471, ...]   → Loss = 0.87
Epoca 500: w = [0.682,   0.891, ...]   → Loss = 0.12
Epoca 999: w = [0.706,   0.897, ...]   → Loss = 0.04  ← bun!
```

**Un neuron singur poate face:**
- Clasificare binară (spam/nu spam)
- Regresie liniară (predicție preț)
- Poartă logică (AND, OR)

**Un neuron singur NU poate face:**
- Clasificare XOR (problemă non-lineară simplă)
- Recunoaștere imagini
- Înțelegere text

Pentru asta avem nevoie de mai mulți neuroni conectați — adică o **rețea neuronală**.

---

### Perceptronul Multistrat — primul pas spre rețea

Conectând mai mulți neuroni în paralel pe un strat, obținem putere de calcul mai mare:

```python
# Strat cu 3 neuroni, fiecare primind 4 input-uri:
import numpy as np

X = np.array([1, 0, 1, 0.8])     # input-ul (4 features)
W = np.random.randn(3, 4)         # 3 neuroni × 4 weights fiecare
b = np.zeros(3)                   # 3 bias-uri

Z = np.dot(W, X) + b              # [z₁, z₂, z₃]
output = np.maximum(0, Z)         # ReLU pe fiecare neuron

print(output)  # [1.23, 0, 0.87]  ← cei 3 neuroni au activat sau nu
```

Acum imaginează-ți că pui mai multe astfel de straturi **unul după altul** — asta este o **rețea neuronală**! Aceasta e subiectul Lecției 11.

---

### Recapitulare

✅ **Neuronul artificial** = sumă ponderată a input-urilor + funcție de activare
✅ **Weights** = ceea ce modelul învață prin gradient descent
✅ **Bias** = offset care ajustează sensibilitatea neuronului
✅ **Funcții de activare** (Sigmoid, ReLU, Tanh) = introduc non-linearitate
✅ **Un singur neuron** poate face clasificare binară, dar e limitat pentru probleme complexe

**Lecția 11** conectează neuronii în rețele cu straturi multiple — și acolo magia devine reală.
