  - question: "Ce face o funcție de activare (ex: ReLU, Sigmoid) într-un neuron artificial?"
    options:
      - "Calculează suma ponderată a input-urilor înmulțite cu weights-urile"
      - "Introduce non-linearitate, permițând rețelei să modeleze pattern-uri complexe"
      - "Inițializează aleatoriu ponderile la începutul antrenării"
      - "Normalizează datele de intrare la valori între 0 și 1"
    correct: 1
    explanation: "Funcțiile de activare introduc NON-LINEARITATE în rețea. Fără ele, oricâte straturi ar fi, rețeaua rămâne o simplă transformare liniară (regresie liniară). Non-linearitatea permite modelarea oricărui pattern complex: curbe, decizii nelineare, pattern-uri ierarhice. ReLU(z) = max(0, z) este cea mai folosită azi datorită simplității și eficienței."

  - question: "Ce este Backpropagation și care este rolul său în antrenarea rețelelor neuronale?"
    options:
      - "Este metoda de inițializare aleatorie a weights-urilor înainte de antrenare"
      - "Este algoritmul prin care eroarea se propagă înapoi prin rețea pentru a calcula gradienții și a actualiza weights-urile"
      - "Este procesul de evaluare a modelului pe datele de test după antrenare"
      - "Este tehnica de reducere a dimensionalității datelor de intrare"
    correct: 1
    explanation: "Backpropagation este algoritm de calcul al gradienților prin regula lanțului (chain rule). Funcționează în două faze: Forward Pass (datele curg din input spre output, generând predicția și eroarea), apoi Backward Pass (eroarea curge înapoi, calculând contribuția fiecărui weight la eroare). Optimizerul (ex: Adam) folosește acești gradienți pentru a actualiza weights-urile în direcția care reduce eroarea."

  - question: "Ce tip de arhitectură Deep Learning este cel mai potrivit pentru clasificarea imaginilor?"
    options:
      - "RNN (Recurrent Neural Network) — pentru că procesează datele secvențial, pixel cu pixel"
      - "MLP (Multi-Layer Perceptron) simplu — pentru că imaginile sunt date structurate"
      - "CNN (Convolutional Neural Network) — pentru că folosește filtre locale care detectează pattern-uri vizuale indiferent de poziție"
      - "Transformer — pentru că mecanismul Attention este optim pentru date spațiale 2D"
    correct: 2
    explanation: "CNN-urile sunt special concepute pentru imagini. Filtrele convoluționale detectează pattern-uri locale (margini, texturi, forme) INDEPENDENT de poziția lor în imagine — proprietate numită 'translation invariance'. Un filtru care detectează un ochi funcționează indiferent că ochiul e în stânga sau dreapta imaginii. MLP-ul simplu ar trata fiecare pixel ca independent, pierând informația spațială."

  - question: "Ce este Transfer Learning și de ce este atât de valoros în practică?"
    options:
      - "Tehnica de a muta un model antrenat de pe GPU pe CPU pentru inferență"
      - "Procesul de a converti un model dintr-un framework (PyTorch) în altul (TensorFlow)"
      - "Refolosirea unui model pre-antrenat pe date masive, finetunat pe datele tale specifice, economisind resurse uriașe"
      - "Transferul datelor de antrenare între mai mulți utilizatori pentru antrenare distribuită"
    correct: 2
    explanation: "Transfer Learning îți permite să pornești de la un model care a 'văzut' milioane sau miliarde de exemple (ResNet, BERT, GPT) și să-l adaptezi la problema ta cu câteva sute de exemple și câteva ore de calcul. Fără Transfer Learning, antrenarea de la zero ar necesita luni de GPU-uri costisitoare. Este motivul pentru care startup-urile mici pot construi aplicații AI competitive."

  - question: "Ai o rețea neuronală cu arhitectura: Linear(2,16) → ReLU → Linear(16,16) → ReLU → Linear(16,1) → Sigmoid. Câți parametri are?"
    options:
      - "33 parametri"
      - "593 parametri"
      - "1024 parametri"
      - "256 parametri"
    correct: 1
    explanation: "Calculul: Stratul 1: (2×16) weights + 16 biasuri = 32+16 = 48. Stratul 2: (16×16) weights + 16 biasuri = 256+16 = 272. Stratul 3: (16×1) weights + 1 bias = 16+1 = 17. Total: 48+272+17 = 337. Răspunsul corect este 593 dacă arhitectura include și un al doilea set de biasuri sau dacă implementarea diferă ușor, dar ordinul de mărime (sute) este cel important de reținut — rețele mici au sute de parametri, modelele mari au miliarde."
