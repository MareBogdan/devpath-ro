## RAG — ce este Retrieval Augmented Generation și de ce e important

LLM-urile au o problemă fundamentală: **nu știu ce s-a întâmplat după data de antrenare** și **nu știu nimic din documentele tale private**. RAG rezolvă ambele.

---

### De ce e nevoie de RAG

```python
# Problema: LLM fără RAG
# Q: "Care sunt rezultatele financiare ale companiei noastre din Q3 2024?"
# A: "Nu am acces la informații confidențiale ale companiei tale."

# Q: "Ce spune documentul de politică internă despre concedii?"
# A: "Nu am acces la documentele interne ale organizației tale."

# Q: "Ce e în știrile de azi?"
# A: "Cunoștințele mele au limita [data de cut-off]."

# Soluția RAG:
# 1. Stochezi documentele tale → Vector DB
# 2. La fiecare întrebare: retrievi chunkurile relevante
# 3. Le bagi în contextul modelului → modelul "știe" conținutul
```

---

### Arhitectura RAG — cei 3 pași

```
FAZA DE INDEXARE (o dată sau când documentele se schimbă):

Document PDF/Word/Web
       ↓
   Chunking (împărțire în bucăți)
       ↓
   Embedding (text → vector)
       ↓
   Vector DB (stochezi vectorii + textul original)

─────────────────────────────────────────────────────

FAZA DE RETRIEVAL + GENERATION (la fiecare întrebare):

Întrebarea utilizatorului
       ↓
   Embedding (întrebare → vector)
       ↓
   Similarity Search în Vector DB → Top-K chunkuri relevante
       ↓
   Context Injection (chunkuri + întrebare → LLM)
       ↓
   Răspuns generat cu informații din documentele tale
```

### Implementare practică cu Supabase pgvector

```python
import os
from openai import OpenAI
from supabase import create_client

openai_client = OpenAI(api_key=os.environ["OPENAI_API_KEY"])
supabase = create_client(os.environ["SUPABASE_URL"], os.environ["SUPABASE_KEY"])

EMBEDDING_MODEL = "text-embedding-3-small"

def chunk_text(text: str, chunk_size: int = 500, overlap: int = 50) -> list[str]:
    """Împarte text în chunkuri cu suprapunere pentru a nu pierde context la granițe"""
    words = text.split()
    chunks = []
    for i in range(0, len(words), chunk_size - overlap):
        chunk = " ".join(words[i:i + chunk_size])
        if chunk:
            chunks.append(chunk)
    return chunks

def get_embedding(text: str) -> list[float]:
    response = openai_client.embeddings.create(
        model=EMBEDDING_MODEL,
        input=text
    )
    return response.data[0].embedding

def index_document(doc_id: str, title: str, content: str) -> int:
    """Indexează un document în Supabase vector store"""
    chunks = chunk_text(content)
    inserted = 0

    for i, chunk in enumerate(chunks):
        embedding = get_embedding(chunk)

        supabase.table("documents").insert({
            "doc_id": doc_id,
            "title": title,
            "chunk_index": i,
            "content": chunk,
            "embedding": embedding,  # pgvector stochează ca vector(1536)
        }).execute()

        inserted += 1

    print(f"Indexat '{title}': {inserted} chunkuri")
    return inserted

# SQL pentru tabelul Supabase (rulat o dată):
# CREATE EXTENSION IF NOT EXISTS vector;
# CREATE TABLE documents (
#   id uuid primary key default gen_random_uuid(),
#   doc_id text not null,
#   title text not null,
#   chunk_index integer not null,
#   content text not null,
#   embedding vector(1536),
#   created_at timestamptz default now()
# );
# CREATE INDEX ON documents USING ivfflat (embedding vector_cosine_ops);
```

### Retrieval — căutare semantică

```python
def retrieve_relevant_chunks(
    query: str,
    top_k: int = 5,
    similarity_threshold: float = 0.7
) -> list[dict]:
    """
    Găsește cele mai relevante chunkuri pentru o întrebare.
    """
    query_embedding = get_embedding(query)

    # Supabase RPC pentru similarity search
    result = supabase.rpc("match_documents", {
        "query_embedding": query_embedding,
        "match_count": top_k,
        "match_threshold": similarity_threshold
    }).execute()

    return result.data

# SQL pentru funcția match_documents:
# CREATE OR REPLACE FUNCTION match_documents(
#   query_embedding vector(1536),
#   match_count integer DEFAULT 5,
#   match_threshold float DEFAULT 0.7
# )
# RETURNS TABLE(id uuid, title text, content text, similarity float)
# LANGUAGE sql STABLE AS $$
#   SELECT id, title, content,
#     1 - (embedding <=> query_embedding) AS similarity
#   FROM documents
#   WHERE 1 - (embedding <=> query_embedding) > match_threshold
#   ORDER BY embedding <=> query_embedding
#   LIMIT match_count;
# $$;
```

### Generation — construiește răspunsul

```python
def rag_answer(question: str, top_k: int = 5) -> dict:
    """
    Pipeline complet RAG: retrieve → augment → generate
    """
    # 1. Retrieval
    relevant_chunks = retrieve_relevant_chunks(question, top_k=top_k)

    if not relevant_chunks:
        return {
            "answer": "Nu am găsit informații relevante în documentele disponibile.",
            "sources": []
        }

    # 2. Augmentation — construiește contextul
    context = "\n\n---\n\n".join([
        f"[Sursă: {chunk['title']}]\n{chunk['content']}"
        for chunk in relevant_chunks
    ])

    # 3. Generation — cu context injectat
    system_prompt = """Ești un asistent care răspunde la întrebări EXCLUSIV pe baza contextului furnizat.
Dacă răspunsul nu se găsește în context, spune explicit: "Nu am această informație în documentele disponibile."
Nu inventa sau extrapola informații. Citează sursa pentru fiecare afirmație importantă."""

    user_message = f"""Context din documentele disponibile:
{context}

---
Întrebare: {question}
Răspunde bazat EXCLUSIV pe contextul de mai sus."""

    response = openai_client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_message}
        ],
        temperature=0.1  # Răspunsuri factuale, puțin creative
    )

    return {
        "answer": response.choices[0].message.content,
        "sources": [chunk["title"] for chunk in relevant_chunks],
        "chunks_used": len(relevant_chunks),
    }

# Exemplu:
result = rag_answer("Care sunt condițiile de rambursare?")
print(f"Răspuns: {result['answer']}")
print(f"Surse: {result['sources']}")
```

### Recapitulare

✅ **RAG = Retrieve + Augment + Generate:** soluția pentru LLM cu documente private/recente
✅ **Indexare:** chunking → embedding → stocare în vector DB (Supabase pgvector)
✅ **Retrieval:** embedding interogare → similarity search → top-K chunkuri relevante
✅ **Generation:** context injectat + instrucțiuni stricte → răspuns bazat pe documente
✅ **Chunking:** împarte documente inteligent — dimensiune și overlap contează
