## Deep Learning

Ai ajuns la una dintre cele mai importante lecții din curs. **Deep Learning** este motivul pentru care AI-ul a explodat în ultimii 10 ani — de la mașini autonome la ChatGPT, totul trece prin acest concept.

---

### Ce înseamnă "Deep"?

**Deep Learning** = rețele neuronale cu **multe straturi ascunse** (de obicei mai mult de 3).

```
Shallow Network (shallow = "puțin adâncă"):
Input → [Strat 1] → Output
        (câteva sute de neuroni)

Deep Network:
Input → [S1] → [S2] → [S3] → ... → [S100] → Output
        (milioane până la miliarde de neuroni)
```

GPT-4 are **96 de straturi** și aproximativ **1.8 trilioane de parametri**. Pentru comparație, creierul uman are ~100 trilioane de conexiuni sinaptice.

---

### De ce "adâncimea" contează

Fiecare strat adaugă un nivel de **abstractizare** — capacitatea de a recunoaște pattern-uri tot mai complexe.

**Exemplu: cum "vede" o rețea adâncă o imagine cu o față:**

```
Pixel brut (Input)
    ↓ Stratul 1 detectează:
Margini și contraste (linii orizontale, verticale)
    ↓ Stratul 2 detectează:
Forme simple (cercuri, unghere)
    ↓ Stratul 3 detectează:
Trăsături (ochi, nas, gură)
    ↓ Stratul 4 detectează:
Combinații de trăsături (față, expresie)
    ↓ Stratul 5+ detectează:
Identitate, emoție, vârstă...
    ↓ Output:
"Această persoană este Maria, 34 ani, zâmbind"
```

Rețelele superficiale nu pot face asta — nu au suficiente straturi de abstractizare.

### Arhitecturi Deep Learning

De-a lungul anilor au apărut arhitecturi specializate pentru tipuri diferite de date:

### 1. CNN — Convolutional Neural Networks (imagini)

CNN-urile sunt optimizate pentru imagini. Nu procesează fiecare pixel în relație cu toți ceilalți (extrem de costisitor) — ci scanează imaginea cu **filtre** care detectează pattern-uri locale.

```python
import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv_layers = nn.Sequential(
            # Filtru 3×3: detectează margini și texturi
            nn.Conv2d(3, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),          # Reducere dimensiune 2×

            # Filtru mai complex: detectează forme
            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 8 * 8, 256),
            nn.ReLU(),
            nn.Linear(256, 10),       # 10 clase
        )

    def forward(self, x):
        x = self.conv_layers(x)
        return self.classifier(x)

# Folosit pentru: clasificare imagini, detectare obiecte,
#                 diagnostic medical, autopilot...
```

### 2. RNN / LSTM — Rețele Recurente (secvențe, text)

RNN-urile sunt concepute pentru **date secvențiale** — text, audio, time series. Au o "memorie" care transportă informații de la un pas la altul.

```python
class TextSentimentRNN(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)

        # LSTM (Long Short-Term Memory) — versiune avansată de RNN
        # Rezolvă problema "uitării" pe secvențe lungi
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)

        self.classifier = nn.Linear(hidden_dim, 2)  # Pozitiv/Negativ

    def forward(self, tokens):
        embedded = self.embedding(tokens)
        output, (hidden, cell) = self.lstm(embedded)
        return self.classifier(hidden[-1])

# "Filmul a fost extraordinar, regia impecabilă" → Pozitiv (98.7%)
# "Am pierdut 2 ore din viața mea" → Negativ (94.2%)
```

### 3. Transformers — Revoluția (text, imagini, audio, cod...)

Transformers (2017, Google) au înlocuit RNN-urile și au produs GPT, BERT, Claude, Stable Diffusion. Folosesc mecanismul de **Attention** pentru a procesa întreaga secvență simultan.

```python
from torch.nn import TransformerEncoder, TransformerEncoderLayer

# Arhitectura de bază a unui Transformer Encoder:
encoder_layer = TransformerEncoderLayer(
    d_model=512,       # Dimensiunea reprezentării interne
    nhead=8,           # 8 capete de attention în paralel
    dim_feedforward=2048,
    dropout=0.1
)
transformer = TransformerEncoder(encoder_layer, num_layers=6)

# Mecanismul Attention permite fiecărui token să "uite" la
# toți ceilalți token-uri simultan → context global
# "Banca a aprobat creditul" → "banca" se referă la instituție
# "Pe malul băncii" → "banca" se referă la mal de râu
# Attention rezolvă ambiguitatea de context!
```

### Transfer Learning — Umeri de uriași

Antrenarea de la zero a unui model mare durează **luni** și costă **milioane de dolari**. Soluția practică: **Transfer Learning**.

> Iei un model pre-antrenat pe milioane de date (ResNet, BERT, GPT) și îl **faci fin-tuning** pe datele tale specifice, cu un cost de calcul mic.

```python
import torchvision.models as models

# ResNet-50: antrenat pe ImageNet (1.2M imagini, 1000 clase)
# Descărci modelul cu ponderile pre-antrenate:
resnet = models.resnet50(pretrained=True)

# Înghețăm straturile anterioare (nu le mai antrenăm):
for param in resnet.parameters():
    param.requires_grad = False

# Înlocuim DOAR ultimul strat cu clasele noastre:
resnet.fc = nn.Linear(2048, 3)  # Clasificare: câine / pisică / iepure

# Antrenăm DOAR ultimul strat pe datele noastre (300 poze):
optimizer = torch.optim.Adam(resnet.fc.parameters(), lr=0.001)

# Rezultat: 94% acuratețe cu DOAR 300 de poze și 10 minute de antrenare!
# Fără transfer learning: ai fi nevoie de 100.000 poze și ore de GPU.
```

**Transfer Learning este motivul pentru care:**
- Startup-uri mici pot concura cu gigantii tech
- Tu poți construi un model decent cu câteva sute de exemple
- Hugging Face (biblioteca de modele pre-antrenate) are peste 500.000 de modele disponibile

### Scaling Laws — Mai mare = Mai bun?

Un fenomen surprinzător descoperit de cercetători: **performanța rețelelor neuronale urmează legi de scalare previzibile**.

```
Parametri model ↑10x → Performanță ↑ (previzibil)
Date antrenare ↑10x → Performanță ↑ (previzibil)
Compute ↑10x → Performanță ↑ (previzibil)
```

Practic, GPT-4 nu e un algoritm complet nou față de GPT-2 — e **mult mai mare** cu **mult mai multe date**. "Emergent abilities" (capacități noi care apar brusc la scale) au surprins chiar și cercetătorii.

---

### Limitele Deep Learning-ului

Deep Learning e puternic, dar nu magic:

```
Provocări reale:
├── Hallucinations — generează fapte false cu încredere maximă
├── Black box — nu înțelegem DE CE face o predicție
├── Bias — preia biasurile din datele de antrenare
├── Costuri energetice — antrenarea GPT-4 a emis CO₂ cât 500 de mașini/an
└── Date masive — funcționează prost cu puține date
```

### Recapitulare

✅ **Deep Learning** = rețele cu multe straturi → abstractizare ierarhică
✅ **CNN** = optimizat pentru imagini (filtre convoluționale)
✅ **RNN/LSTM** = optimizat pentru secvențe (memorie temporală)
✅ **Transformers** = arhitectura modernă dominantă (Attention mechanism)
✅ **Transfer Learning** = refolosești modele pre-antrenate → eficiență uriașă
