## Ce este un Language Model — cum prezice următorul cuvânt

Ești la mijlocul acestui curs și înțelegi deja cum funcționează rețelele neuronale, cum sunt antrenate și ce înseamnă Deep Learning. Acum vine întrebarea care leagă totul de lumea reală:

**Cum funcționează exact ChatGPT, Claude, Gemini și restul LLM-urilor?**

Răspunsul începe cu un concept surprinzător de simplu: **predicția următorului cuvânt**.

---

### Problema de bază: ce urmează după?

Un Language Model (LM) este, în esență, un model care răspunde la o singură întrebare:

> **Dată o secvență de cuvinte, care este cel mai probabil cuvânt următor?**

```
Input:  "Pisica stă pe"
Output: P("canapea") = 0.34
        P("masă")    = 0.21
        P("acoperiș") = 0.12
        P("fotoliu")  = 0.09
        ...
```

Această sarcină aparent simplă — „prezice cuvântul următor" — se dovedește a fi extraordinar de puternică. Un model care prezice bine cuvântul următor trebuie să înțeleagă gramatică, semantică, context, fapte despre lume, raționament logic și mult mai mult.

---

### De la modele statistice la rețele neuronale

**Modelele n-gram (pre-2013):**

Primele modele de limbaj calculau probabilitățile din statistici simple:

```python
# N-gram model: probabilitate bazată pe ultimele N-1 cuvinte
# Bigram: P(cuvant | cuvant_anterior)

corpus = ["pisica stă pe canapea", "pisica doarme pe fotoliu", ...]

# P("canapea" | "pe") = count("pe canapea") / count("pe")
# = 234 / 891 = 0.26
```

Problema: pentru a prezice corect ai nevoie de context lung, dar n-gram-urile sunt limitate la 2-5 cuvinte înapoi. "Băiatul care a câștigat concursul național de matematică din clasa a XI-a este ___" — modelul n-gram ar ignora tot contextul relevant.

**Rețelele neuronale recurrente (2013-2017):**

RNN-urile și LSTM-urile au rezolvat parțial problema contextului lung prin procesare secvențială cu memorie internă. Dar aveau o limită critică: procesarea secvențială (cuvânt după cuvânt) nu putea fi paralelizată pe GPU.

**Transformers (2017-prezent):**

Arhitectura Transformer, introdusă în paper-ul "Attention is All You Need" (2017), a rezolvat ambele probleme. O vom studia în detaliu în Lecția 16.

### Autoregressive Generation — cum generezi text

Odată antrenat să prezică cuvântul următor, un LM poate genera text prin **autoregresie**: folosești outputul ca input pentru pasul următor.

```python
import openai

# Conceptual: how autoregressive generation works
def generate_text(prompt, max_tokens=50):
    generated = prompt.split()

    for _ in range(max_tokens):
        # Model predicts probability distribution over vocabulary
        probabilities = model.predict(generated)

        # Sample from distribution (temperature controls randomness)
        next_token = sample(probabilities, temperature=0.7)

        generated.append(next_token)

        # Stop at end-of-sequence token
        if next_token == "<EOS>":
            break

    return " ".join(generated)

# Example execution:
# Input:   ["Cel", "mai", "bun", "limbaj", "de", "programare", "este"]
# Step 1:  → "Python" (p=0.41)
# Step 2:  → "deoarece" (p=0.28)
# Step 3:  → "este" (p=0.19)
# Step 4:  → "simplu" (p=0.35)
# ...
```

**Temperature:** controlează "creativitatea" generării:
```
temperature = 0.0  → deterministă (mereu alege cel mai probabil token)
temperature = 0.7  → echilibru (recomandat pentru chat)
temperature = 1.5  → haotic, creativ dar mai puțin coerent
```

### Antrenarea unui Language Model

Antrenarea este un caz special de **supervised learning**, unde datele de antrenare se generează **automat din text**:

```
Text original:  "Inteligența artificială schimbă lumea"

Perechi input → target generate automat:
  Input: ["Inteligența"]                              → Target: "artificială"
  Input: ["Inteligența", "artificială"]               → Target: "schimbă"
  Input: ["Inteligența", "artificială", "schimbă"]    → Target: "lumea"
```

Asta înseamnă că **orice text neannotat devine date de antrenare**. GPT-4 a fost antrenat pe sute de miliarde de tokeni — cărți, articole, cod sursă, pagini web.

**Scara antrenării:**
```
GPT-2  (2019): 1.5 miliarde parametri, 40GB text
GPT-3  (2020): 175 miliarde parametri, 570GB text
GPT-4  (2023): ~1.7 trilioane parametri (estimat), petabytes de date
Llama 3 (2024): 70-405 miliarde parametri, 15 trilioane tokeni
```

### Perplexity — cât de "surprins" e modelul

**Perplexity** este metrica principală de evaluare a unui LM:

```python
# Perplexity intuitiv:
# Dacă modelul ar trebui să ghicească aleatoriu dintr-un vocabular de N cuvinte
# Perplexity ≈ N (modelul e complet pierdut)
# Dacă Perplexity = 10, modelul se comportă ca și cum ar alege din 10 cuvinte posibile

# Perplexity scăzut = model mai bun
# GPT-2: ~35 pe Wikipedia engleză
# GPT-3: ~20
# GPT-4: estimat <15

import numpy as np

def perplexity(log_probs):
    """
    log_probs: log probabilitățile atribuite cuvintelor corecte
    """
    n = len(log_probs)
    return np.exp(-np.sum(log_probs) / n)

# Exemplu:
log_probs = [-0.5, -0.8, -0.3, -1.2, -0.6]  # log P(cuvant_corect)
print(f"Perplexity: {perplexity(log_probs):.2f}")  # → ~2.1
```

### De la Language Model la Chatbot — RLHF

Un LM antrenat pe text brut poate continua orice text, dar nu e neapărat util sau sigur. GPT-3 de bază, de exemplu, dacă primește promptul "Cum fac o bombă?", ar continua textul cu instrucțiuni deoarece a văzut acest tip de conținut în date.

**RLHF — Reinforcement Learning from Human Feedback:**

```
1. Supervised Fine-Tuning (SFT):
   - Antrenezi LM-ul pe conversații demo scrise de umani
   - Modelul învață formatul întrebare-răspuns

2. Reward Model:
   - Umani compară 2 răspunsuri și aleg care e mai bun
   - Se antrenează un model separat să prezică preferința umană

3. PPO (Reinforcement Learning):
   - LM-ul e antrenat să maximizeze scorul Reward Model-ului
   - Rezultat: model care răspunde util, sigur și aliniat cu valorile umane
```

Asta e diferența dintre `GPT-3 base` (poate continua text) și `ChatGPT` (poate purta conversații utile).

### Large Language Models în practică

**Ce pot face:**
- Generare de text (articole, cod, poezii)
- Rezumare
- Traducere
- Răspunsuri la întrebări
- Raționament (cu limitări)
- Few-shot learning (fără re-antrenare!)

**Ce nu pot face:**
- Accesa internet în timp real (fără tools)
- Calcula exact cu numere mari (nu sunt calculatoare)
- Reține conversații anterioare (fără memorie externă)
- Ști ce s-a întâmplat după data de cut-off

---

### Recapitulare

✅ **Language Model:** prezice probabilitatea cuvântului următor dat contextul anterior
✅ **Autoregresie:** generează text token cu token, folosind outputul ca input
✅ **Antrenarea:** supervised learning pe text neannotat (input = context, target = token următor)
✅ **Perplexity:** metrica principală — cât de surprins e modelul de textul real
✅ **RLHF:** transformă LM brut în chatbot util și sigur prin feedback uman
