# Instrucțiuni Negative în Prompting

În comunicarea de zi cu zi, spunem adesea ce vrem să se întâmple. Dar uneori, ceea ce nu vrem este la fel de important — dacă nu mai important — decât ceea ce vrem.

**Instrucțiunile negative** (sau constrainturile negative) sunt elementele din prompt care îi spun modelului ce să evite, ce să nu includă sau ce să nu facă. Adăugate strategic, pot îmbunătăți dramatic precizia output-ului.

## De ce sunt necesare instrucțiunile negative?

Modelele de limbaj au comportamente implicite — tendințe "default" dobândite din datele de training. Fără instrucțiuni contrare, vor:

- Adăuga introduceri lungi și disclaimere înainte de conținutul util
- Folosi clișee și formulări de tip "Desigur!", "Cu siguranță!", "Excelentă întrebare!"
- Genera răspunsuri "echilibrate" când tu vrei o poziție clară
- Include jargon tehnic chiar dacă audiența ta nu îl înțelege
- Structura răspunsul ca un eseu academic chiar dacă vrei bullet points

Instrucțiunile negative te ajută să suprascrii aceste comportamente implicite.

## Tipuri de instrucțiuni negative

### 1. Fără conținut specific

```
Scrie o descriere de produs pentru căștile noastre wireless.
Fără: "excepțional", "de înaltă calitate", "premium", "produs remarcabil".
Fără clișee de marketing. Focusează pe specificații concrete și beneficii măsurabile.
```

### 2. Fără format nedorit

```
Explică ce este blockchain.
Nu folosi introduceri lungi. Nu folosi concluzie. Răspunde direct cu conținutul.
Nu mai mult de 200 de cuvinte.
```

### 3. Fără abordare sau perspectivă nedorită

```
Analizează decizia mea de a lăsa jobul corporativ pentru freelancing.
Nu îmi spune că este riscant — știu asta. Nu îmi da sfaturi generice despre "rezerva financiară".
Focusează-te pe: ce pași concreți să fac în primele 60 de zile.
```

### 4. Fără asumpții nedorite

```
Scrie un email de follow-up după o întâlnire de business.
Nu presupune că întâlnirea a mers bine. Nu presupune că există un deal în derulare.
Tonul trebuie să fie neutru și profesional.
```

### 5. Fără comportamente verbale generice

```
Ești asistentul meu de writing. Când îți cer feedback, dă feedback direct.
Nu spune "Desigur!", "Cu plăcere!", "Excelentă întrebare!" sau alte confirmări.
Treci direct la conținut.
```

## Instrucțiuni negative vs. pozitive — când să alegi ce

Nu toate constrainturile funcționează mai bine ca negative. Regula generală:

**Preferă forma pozitivă** când poți spune exact ce vrei:

Negativ (mai slab): "Nu folosi un ton formal."
Pozitiv (mai bun): "Folosește un ton conversațional, ca și cum ai explica unui prieten."

**Folosește forma negativă** când:
- Vrei să elimini un comportament default al modelului care nu poate fi descris simplu în pozitiv
- Ai o listă de elemente specifice de evitat (clișee, termeni, structuri)
- Contextualizezi o restricție mai degrabă decât o preferință pozitivă

```
Scrie un articol despre productivitate.
Nu include sfaturi despre meditație, "morning routines" sau tehnica Pomodoro.
Audiența citise deja aceste sfaturi de 100 de ori. Vrem perspective neconvenționale.
```

## Instrucțiunile negative ca parte din sistem prompt

Instrucțiunile negative strălucesc cel mai mult când construiești un comportament consistent pentru o sesiune mai lungă de lucru sau pentru un asistent personalizat:

```
Ești editorul meu de conținut pentru newsletter-ul săptămânal.

Reguli generale:
- Scrie la persoana a 2-a singular
- Ton: direct, fără paternalism
- Lungimea secțiunilor: maxim 150 cuvinte fiecare

Instrucțiuni FĂRĂ:
- Fără "Desigur că" la începutul oricărui răspuns
- Fără "Sper că ți-a fost de folos!" sau variante
- Fără formatare cu Bold excesiv
- Fără paragrafe de tranziție goale ("Acum că am văzut X, să explorăm Y")
- Fără clișee: "eficiență maximă", "impact pozitiv", "nivel următor", "game changer"
```

## Construcția unui "Negative System Prompt" personal

Odată ce identifici comportamentele modelului care te deranjează frecvent, poți construi o listă personalizată de instrucțiuni negative pe care o adaugi la fiecare sesiune de lucru:

```
Preferințe generale:
- Răspunsuri directe, fără introduceri
- Fără disclaimere inutile ("Ca model AI, nu pot...")
- Fără a cere confirmare la fiecare pas ("Doriți să continui cu X?")
- Fără a repeta instrucțiunile din prompt în răspuns
- Fără formatare excesivă pentru răspunsuri scurte
```

## Exerciții practice

**Exercițiu 1 — Identifică comportamentele nedorite:**
Trimite un prompt simplu fără instrucțiuni negative. Notează în răspuns tot ce nu ți-a plăcut (tone, cuvinte, structură, lungime). Construiește un set de instrucțiuni negative și retrimite prompt-ul.

**Exercițiu 2 — Curăță un output de clișee:**
Iei un text generat anterior de AI și identifici toate clișeele sau expresiile generice. Construiește un prompt cu instrucțiuni negative care le elimină și regenerează textul.

**Exercițiu 3 — Lista personalizată:**
Construiește-ți lista personală de instrucțiuni negative pentru tipul de muncă pe care îl faci cel mai des cu AI (copywriting, analiză, cod, comunicare). Salvează-o și folosește-o consistent.

## Concluzie

Instrucțiunile negative sunt instrumentul de precizie al prompt engineering-ului. Nu le folosi excesiv — un prompt cu 20 de "nu face" devine greu de urmărit. Dar câteva instrucțiuni negative bine alese pot face diferența dintre un output generic și unul adaptat exact stilului și nevoilor tale.

**Regula practică:** Dacă ceva din output-ul unui model te deranjează repetat, adaugă o instrucțiune negativă specifică. Cu timpul, vei construi un set personal de constrainturi care îți vor economisi iterații la fiecare sesiune de lucru.
