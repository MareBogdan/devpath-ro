# Ce Este un Prompt?

Un **prompt** este orice text pe care îl trimiți unui model de limbaj (LLM — Large Language Model) pentru a obține un răspuns. Sună simplu, dar în spatele acestei definiții se ascunde una dintre cele mai importante abilități ale erei AI: capacitatea de a comunica eficient cu inteligența artificială.

Dacă știi să scrii prompt-uri bune, poți transforma un model de limbaj obișnuit într-un asistent de cercetare, un editor profesionist, un profesor răbdător, un analist de date sau un programator — fără să instalezi nimic și fără să cunoști un singur rând de cod.

## De ce contează prompt-ul?

Modelele de limbaj sunt instrumente extraordinar de capabile, dar fundamental pasive. Ele nu știu cine ești, ce vrei, ce context ai sau în ce format dorești răspunsul. **Tot ce știu este ce le spui în prompt.**

Gândește-te la un LLM ca la un consultant extrem de experimentat, dar care nu a mai vorbit niciodată cu tine. În primul moment, nu știe nimic despre proiectul tău, industria ta sau preferințele tale. Dacă îi trimiți un email vag, va da un răspuns vag. Dacă îi oferi context detaliat, obiective clare și format dorit, va produce muncă de calitate profesională.

**Exemplu concret — același model, două prompt-uri:**

Prompt slab:
```
Ajută-mă cu marketingul
```

Prompt bun:
```
Ești un consultant de marketing digital cu experiență în startup-uri SaaS B2B.
Am un produs de management de proiecte, 50 de clienți actuali, buget de 3.000 lei/lună.
Obiectiv: 20 de clienți noi în 90 de zile.
Generează 5 idei concrete de campanii, cu canal, mesaj cheie și estimare de buget pentru fiecare.
```

Primul prompt va returna sfaturi generice găsite pe orice blog de marketing. Al doilea va produce un plan acționabil, adaptat situației tale specifice. **Modelul este identic — diferența este 100% în calitatea prompt-ului.**

## Cum procesează un LLM prompt-ul tău?

Înțelegerea mecanismului intern te ajută să construiești prompt-uri mai eficiente.

**Pasul 1 — Tokenizarea.** Textul tău este transformat în unități numite *tokens* (aproximativ 0.75 cuvinte pe token în engleză, puțin mai puțin în română). Modelul nu vede litere sau cuvinte — vede secvențe de tokeni numerici.

**Pasul 2 — Embedding.** Fiecare token este transformat într-un vector numeric în spațiu de sute sau mii de dimensiuni. Cuvinte similare ca sens ocupă regiuni similare în acest spațiu matematic.

**Pasul 3 — Attention.** Mecanismul de atenție calculează relațiile dintre toți tokenii din prompt. Aceasta permite modelului să "înțeleagă" că pronumele "el" dintr-o propoziție se referă la un substantiv menționat anterior.

**Pasul 4 — Generarea token cu token.** Răspunsul este generat secvențial: modelul prezice cel mai probabil token următor, îl adaugă la context, prezice următorul, și așa mai departe.

**Implicație practică importantă:** Modelul nu "gândește" în sensul uman. Nu raționează deliberat. El activează pattern-uri statistice învățate din trilioane de exemple de text. Cu cât prompt-ul tău seamănă mai mult cu un text de calitate pe care modelul l-a văzut în training, cu atât mai bun va fi răspunsul.

## Anatomia de bază a unui prompt

Orice prompt — de la cel mai simplu la cel mai complex — conține unul sau mai multe dintre aceste elemente:

**1. Instrucțiunea** — Ce vrei să facă modelul:
```
Traduce textul următor în engleză formală.
```

**2. Contextul** — Informații de fundal care ajută modelul să răspundă relevant:
```
Contextul: Lucrez la o companie de software din România și vreau să trimit un email unui partener american.
```

**3. Input-ul** — Datele specifice pe care modelul trebuie să le proceseze:
```
Text de tradus: "Vă mulțumim pentru colaborare și așteptăm cu nerăbdare întâlnirea de săptămâna viitoare."
```

**4. Indicatorul de output** — Formatul sau structura dorită:
```
Format: email formal de business, paragraf unic, maxim 3 propoziții.
```

Un prompt complet care combină toate patru:
```
Ești un traducător profesionist specializat în comunicare de business.
Contextul: Email formal de la o companie românească către un partener american.
Traduce textul următor menținând tonul formal și politețea:
"Vă mulțumim pentru colaborare și așteptăm cu nerăbdare întâlnirea de săptămâna viitoare."
Format: Un singur paragraf, maxim 2 propoziții, English formal business style.
```

## Tipuri de prompt-uri

**Prompt simplu (one-shot):** O singură instrucțiune directă, fără context adițional. Funcționează excelent pentru sarcini clare și bine definite.
```
Calculează: câte secunde sunt într-un an?
```

**Prompt cu context:** Adaugi informații relevante care nu sunt evidente din instrucțiune.
```
Audiența mea sunt antreprenori români cu vârste între 35-50 ani, fără background tehnic.
Explică ce este cloud computing în maxim 100 de cuvinte, fără jargon.
```

**Prompt conversațional:** Construiești pe răspunsurile anterioare, rafinând sau extindend.
```
Tu: Scrie un titlu pentru un articol despre productivitate.
AI: "10 Metode Dovedite să Îți Dublezi Productivitatea în 30 de Zile"
Tu: Fă-l mai specific pentru programatori.
AI: "10 Tehnici de Productivitate Testate de Ingineri Software la Google și Netflix"
```

**Prompt structurat:** Organizezi clar diferitele componente folosind etichete sau secțiuni.
```
ROL: Expert în SEO cu 8 ani experiență
AUDIENȚĂ: Proprietari de magazine online românești
TASK: Scrie meta description pentru un produs
PRODUS: Căști wireless Bluetooth, reducere 30%
FORMAT: Maxim 155 caractere, include beneficiul principal și un CTA
```

## Principii fundamentale ale unui prompt eficient

**Specificitate bate generalitate.** "Scrie un email de 150 de cuvinte de mulțumire pentru un client care a recomandat 3 persoane noi" este incomparabil mai bun decât "Scrie un email de mulțumire".

**Acțiunea bate descrierea.** Folosește verbe de acțiune: *listează, compară, analizează, creează, reformulează, evaluează* — nu *spune-mi despre, vorbește-mi de*.

**Contextul elimină ambiguitatea.** Nu presupune că modelul știe că ești un medic, că proiectul tău e un SaaS, sau că audiența ta sunt studenți. Dacă nu îi spui, va ghici — și va ghici greșit.

**Formatul explicit economisește iterații.** Dacă vrei un tabel, o listă numerotată, un răspuns de 3 paragrafe sau JSON — spune asta explicit. Altfel modelul alege el, și rareori alege ce ai nevoie tu.

## Exerciții practice

**Exercițiu 1:** Ia un prompt pe care l-ai folosit recent cu ChatGPT sau Claude și adaugă: (a) un rol, (b) context specific, (c) format dorit. Compară calitatea răspunsului.

**Exercițiu 2:** Trimite același subiect cu două versiuni — una vagă, una specifică:
```
Versiunea vagă: "Explică-mi ce este machine learning."

Versiunea specifică: "Ești profesor de informatică pentru liceeni fără background tehnic.
Explică machine learning în exact 3 paragrafe scurte, fiecare cu o singură idee.
Folosește o singură analogie din viața de zi cu zi, fără formule matematice."
```

Diferența de calitate te va convinge mai mult decât orice explicație teoretică.

## Concluzie

Un prompt nu este o întrebare — este o specificație. Cu cât mai completă și mai precisă este specificația, cu atât mai mult valoare extrage din model.

În lecțiile din acest modul vei învăța exact cum să construiești această specificație: care sunt componentele esențiale, ce greșeli să eviți și ce tehnici avansate să aplici. Fiecare tehnică este concretă, testabilă imediat și aplicabilă în munca ta de zi cu zi.

**Prompt engineering nu este știință rocket — este comunicare precisă.** Și aceasta se poate învăța.
