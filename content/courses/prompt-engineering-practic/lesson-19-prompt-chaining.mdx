# Prompt Chaining: Lanțuri de Prompturi

Tehnicile pe care le-am explorat — Chain-of-Thought, Tree of Thought, ReAct — îmbunătățesc procesul de raționament al unui singur apel. **Prompt Chaining** abordează o problemă diferită: ce faci când sarcina este prea complexă pentru un singur prompt?

## Principiul Prompt Chaining

Prompt Chaining înseamnă **descompunerea unei sarcini complexe în pași mai mici** și trimiterea output-ului fiecărui pas ca input pentru pasul următor. Fiecare "verigă" din lanț este un prompt specializat, optimizat pentru subtask-ul său specific.

Fluxul de bază:

    Sarcina complexă
         ↓
    Prompt 1: Subpas A → Output A
         ↓
    Prompt 2: Subpas B, folosind Output A → Output B
         ↓
    Prompt 3: Subpas C, combinând A și B → Output Final

## Când folosești Prompt Chaining?

Indicii că ai nevoie de chaining, nu de un prompt mai lung:

- **Sarcina are faze distincte** cu cerințe diferite (ex: mai întâi analiză, apoi scriere)
- **Contextul unui singur prompt devine prea lung** pentru a menține calitatea
- **Vrei validare intermediară** — poți verifica output-ul între pași
- **Diferite subpasuri necesită parametri diferiți** (ex: temp joasă pentru analiză, ridicată pentru scriere)
- **Procesezi colecții** — aplici aceeași transformare la multe elemente

## Exemplu concret: creare de conținut de blog

Sarcina complexă: "Scrie un articol de blog complet despre machine learning pentru începători."

**Fără chaining** (un prompt): Rezultat mediu — modelul încearcă să facă totul simultan.

**Cu chaining** (4 pași):

    PROMPT 1: Cercetare și structură
    Analizează audiența articolului (studenți fără background tehnic) și propune:
    1. Un titlu captivant (5 variante)
    2. Structura articolului (secțiuni principale cu subtitluri)
    3. 3 exemple concrete din viața reală pe care le vom folosi
    4. Tonul și stilul recomandat

    PROMPT 2: Draft secțiunea 1
    Folosind structura de mai sus, scrie secțiunea "Ce este Machine Learning"
    în stilul definit. Obligatoriu: include exemplul cu filtrul de spam email.
    Lungime: 300-400 cuvinte.

    PROMPT 3: Draft secțiunile 2-3
    Continuând stilul stabilit, scrie secțiunile "Cum funcționează" și "Tipuri de ML"...

    PROMPT 4: Revizuire și polish
    Revizuiește întregul articol pentru:
    - Consistență stilistică
    - Fluxul logic între secțiuni
    - Adaugă intro captivant și concluzie cu CTA

## Tipuri de Prompt Chaining

### Chaining secvențial (cel mai comun)

    Input → Prompt1 → Prompt2 → Prompt3 → Output Final

Fiecare prompt primește output-ul celui precedent.

### Chaining paralel

    Input → Prompt1 → Output1 ─┐
    Input → Prompt2 → Output2 ──→ Prompt Consolidare → Output Final
    Input → Prompt3 → Output3 ─┘

Utile când vrei perspective multiple consolidate.

### Chaining condițional

    Input → Prompt Clasificare → dacă tip=A → PromptA
                                             ↘
                                dacă tip=B → PromptB

Output-ul unui prompt determină ce prompt urmează.

## Implementare practică (pseudo-cod)

    async function processWithChaining(input) {
      // Pasul 1: Analiză
      const analysis = await callLLM({
        prompt: "Analizează: " + input,
        temperature: 0.2
      });

      // Pasul 2: Draft
      const draft = await callLLM({
        prompt: "Pe baza analizei: " + analysis + " Scrie draft-ul...",
        temperature: 0.7
      });

      // Pasul 3: Revizuire
      const final = await callLLM({
        prompt: "Revizuiește și îmbunătățește: " + draft,
        temperature: 0.3
      });

      return final;
    }

## Gestionarea erorilor în lanț

O problemă critică: erorile se propagă. Dacă Prompt 1 produce output greșit, Prompt 2 va construi pe o bază greșită.

Strategii de robustitate:

**Validare intermediară**: după fiecare pas critic, verifici output-ul (manual sau automat).

**Prompt-uri cu fallback**: "Dacă output-ul anterior pare incomplet sau greșit, notifică explicit în loc să continui."

**Structurare strictă a output-urilor**: cere JSON la fiecare pas pentru a putea valida programatic.

## Prompt Chaining vs. Un Prompt Lung

| Aspect | Prompt Lung | Prompt Chaining |
|--------|-------------|-----------------|
| Calitate | Scade pe sarcini complexe | Constantă per subpas |
| Validare | Imposibilă intermediar | Posibilă între pași |
| Cost | 1 apel, dar context mare | Multiple apeluri |
| Debuggabilitate | Greu | Ușor (izolezi pasul problematic) |
| Flexibilitate | Redusă | Ridicată |

## Exemplu real: pipeline de analiză a recenziilor

    Pasul 1 — Extragere
    "Din recenzia: [text]
    Extrage: sentiment, produsul, aspectele menționate (JSON)"

    Pasul 2 — Clasificare
    "Pe baza aspectelor: [output_1]
    Clasifică fiecare ca 'produs', 'livrare', 'suport', 'preț'"

    Pasul 3 — Acțiune recomandată
    "Bazat pe analiza: [output_2]
    Ce acțiune recomanzi echipei de produs? (maxim 50 cuvinte)"

Fiecare pas este simplu, verificabil, și face exact un singur lucru.

## Concluzie

Prompt Chaining este una dintre tehnicile cele mai practice și imediat aplicabile din ingineria de prompturi. Nu necesită configurări complexe de agenți sau framework-uri externe — doar gândire clară despre descompunerea sarcinii. Principiul de bază este universal în inginerie software: **divide și cucerește**.
