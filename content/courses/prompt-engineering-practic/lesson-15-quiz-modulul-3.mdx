  - question: "Ce este un system prompt?"
    options:
      - "Primul mesaj al utilizatorului într-o conversație"
      - "Un set de instrucțiuni date modelului înainte de orice conversație cu utilizatorul"
      - "Un tip special de mesaj care face modelul mai rapid"
      - "Documentația tehnică a modelului AI"
    correct: 1
    explanation: "Un system prompt definește comportamentul, personalitatea și restricțiile modelului pentru o sesiune specifică. Este invizibil pentru utilizatorul final și este procesat înaintea oricărui mesaj al utilizatorului — stratul invizibil care setează 'regulile jocului' pentru întreaga conversație."

  - question: "Ce reprezintă 'fereastra de context' (context window)?"
    options:
      - "Interfața grafică a aplicației AI"
      - "Numărul de utilizatori simultani ai modelului"
      - "Cantitatea maximă de text pe care modelul o poate procesa simultan"
      - "Numărul de ore în care modelul este disponibil"
    correct: 2
    explanation: "Fereastra de context este 'memoria de lucru' a modelului — cantitatea maximă de text (măsurată în tokeni) pe care o poate procesa la un moment dat. Tot ce depășește această limită este ignorat complet. Gestionarea corectă a contextului este esențială pentru aplicații complexe."

  - question: "Care este efectul setării temperature = 0.0 la un model AI?"
    options:
      - "Modelul nu poate genera niciun răspuns"
      - "Modelul selectează întotdeauna tokenul cu probabilitatea cea mai mare, producând output consistent și deterministic"
      - "Modelul generează text complet aleator, fără logică"
      - "Modelul folosește mai puțini tokeni și răspunde mai rapid"
    correct: 1
    explanation: "Temperature = 0.0 face generarea deterministă: același prompt produce (aproape) același răspuns de fiecare dată. Este ideal pentru clasificare, extragere de date, code generation — orice situație unde consistența și precizia contează mai mult decât creativitatea."

  - question: "Care strategie de management al contextului este cea mai eficientă pentru un asistent care trebuie să cunoască o documentație de 500 de pagini?"
    options:
      - "Injectarea întregii documentații în fiecare system prompt"
      - "Trunchierea documentației la primele 10 pagini"
      - "Retrieval Augmented Generation (RAG) — recuperarea secțiunilor relevante la runtime"
      - "Eliminarea documentației și lăsarea modelului să improvizeze"
    correct: 2
    explanation: "RAG (Retrieval Augmented Generation) permite stocarea documentației într-o bază de date vectorială și recuperarea doar a secțiunilor relevante pentru fiecare interogare. Injectarea întregii documentații ar depăși orice context window și ar fi extrem de costisitoare. RAG rezolvă elegant problema scalabilității."
